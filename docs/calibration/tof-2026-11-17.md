# ToF (VL53L5CX) 검증 — 2026-11-17

센서: SparkFun VL53L5CX (SEN-18642), UGV02 앞판 정중앙, 보드 세로 장착, 수평. Pi I2C-1 (0x29), 기본 100 kHz.
도구: `tools/lab/tof_lab.py` (ROS 없이 직접, Pimoroni `vl53l5cx-ctypes`, venv `~/tof-venv`). 아직 로봇 기능에는 안 씀.
권한: `/dev/i2c-1` → 사용자를 `i2c` 그룹에 추가 (`sudo usermod -aG i2c $USER`).

## 1. 방향 (손 가리기)
- 로봇 정면에서 오른쪽(= 로봇 왼쪽)·아래·왼쪽(= 로봇 오른쪽) 순서로 가림 → raw 아래 줄 = 로봇 왼쪽, raw 오른쪽 열 = 아래, raw 위 줄 = 로봇 오른쪽.
- **`np.rot90(raw, 3)` (시계 90°)** → 위 = 위, 왼 = 로봇 왼쪽. 거울 뒤집기 없음. (처음 기본값 rot 1 은 반대였음)
- 확인: 로봇 뒤에서 손을 왼쪽 앞에서 천천히 넣음 → 표 왼쪽 열부터 차례로 8~9 cm. 맞음.

## 2. 가림
- 6 cm 안쪽 "늘 가까운" 칸 없음 → 스페이서·차체가 시야를 안 가림.

- 가장자리 칸도 가운데와 같은 값 (평면 벽에서 30/30, 50/50) → 칸마다 벽까지 수직 거리처럼 나옴 [해석, 데이터시트 확인 안 함].

## 4. 바닥
- 아래 1줄 ≈ 24 cm, 아래 2번째 줄 ≈ 32 cm 에서 바닥 (벽이 더 멀 때).
- 수평 장착 가정, 시야 45° / 8 줄 → 줄 가운데 각 −19.7°, −14.1° → 높이 ≈ 24·sin19.7° = **8.1 cm**, 32·sin14.1° = **7.8 cm** (계획 h ≈ 8.5 cm 와 비슷) [해석, 줄자로 높이 확인 필요].
- 벽 50 cm 일 때 아래 2번째 줄이 41~44 cm (바닥 32 와 벽 50 사이) → **한 칸에 두 물체가 걸치면 섞인 값 하나** [해석]. 장애물 판단에 쓸 때 주의.

## 5. 속도
- 7.5~7.6 Hz (설정 15 Hz). I2C 100 kHz 때문으로 추정 → 기능으로 쓸 때 `config.txt` `dtparam=i2c_arm=on,i2c_arm_baudrate=400000` 후 재측정.

## 6. 기타
- Ctrl+C 가 라이브러리 콜백 안에서 걸리면 예외가 삼켜져 안 꺼짐 → SIGINT 를 표시만 하고 루프에서 끝내게 고침.
