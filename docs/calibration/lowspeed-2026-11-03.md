# 저속 주행 측정 (2026-11-03 밤, 거실 바닥, 배터리 11.0~11.4 V)

> 목표: "맷돌을 천천히 돌리듯" 잔잔하게 기어가는 로봇 (Jasper). 소음·안전·야간 주행.
> 덜컹 = IMU ax 표준편차 (정지 상태 기준 24.5). 속도 = odl/odr 누적 거리 / 시간.

## 1. 펌웨어 PID (T:1, 기본 P=20 I=2000)
| 명령 m/s | 실제 m/s | 덜컹 | 피드백 속도 0 비율 |
|---|---|---|---|
| 0.03 | 0.024 | 454 | 73% |
| 0.05 | 0.051 | 456 | 59% |
| 0.08 | 0.089 | 442 | 33% |
| 0.10 | 0.127 | 515 | 11% |
→ 속도는 따라가지만 모든 속도에서 덜컹 ~450 (정지의 18배).

## 2. PID 값 바꾸기 (T:2)
| P | I | 0.03 → 실제 / 덜컹 | 0.05 → 실제 / 덜컹 |
|---|---|---|---|
| 20 | 2000 | 0.038 / 353 | 0.056 / 341 |
| 20 | 500 | 0.007 / 176 | 0.036 / 154 |
| 10 | 200 | 0.000 / 21 (안 움직임) | 0.022 / 169 |
→ 약하게 하면 덜 출렁이지만 출발할 힘도 사라짐. 원인: 펌웨어가 짧은 주기로 속도를 재서 저속에선 대부분 0 → 과반응.

## 3. 일정한 힘 (T:11 PWM, 펌웨어 PID 끔) — 직진
| PWM | 실제 m/s | 덜컹 |
|---|---|---|
| 20 | 0.000 | 29 |
| 30 | 0.080 | 92 |
| 40 | 0.138 | 150 |
| 50 | 0.180 | 175 |
| 60 | 0.244 | 193 |
| 80 | 0.340 | 320 |
→ 같은 0.08 m/s 에서 덜컹 92 vs PID 441 (**1/5**). 가다 서다 없음 (Jasper 육안). 덜컹은 속도에 비례하는 자연 진동.

## 4. 출발만 세게 (PWM 40 × 0.3 s) → 유지
| 유지 PWM | 실제 m/s | 덜컹 |
|---|---|---|
| 28 | 0.066 | 100 |
| 26 | 0.070 | 110 |
| 24 | 0.056 | 187 |

→ 정지마찰만 넘기면 PWM 22 로도 **0.056 m/s 를 멈춤 없이** 유지 (육안 확인).

## 5. 제자리 회전 (출발 PWM 60 × 0.3 s → 유지, L = −R)
| 유지 PWM | 회전 °/s (rad/s) | 회전 출렁임 °/s |
|---|---|---|
| 30 | 0.0 | — (멈춤) |
| 40 | 7.5 (0.13) | 2.1 |
| 50 | 20.2 (0.35) | 4.2 |
| 60 | 36.9 (0.64) | 3.4 |
→ 스키드 스티어라 회전은 바퀴를 옆으로 끌어야 해서 힘이 훨씬 많이 듦. 최저 ≈ PWM 40 / 0.13 rad/s.
  출발 때 덜컹 → 유지 (멈추진 않음, 육안).

## 결론
- 한계는 **하드웨어가 아니라 펌웨어 속도 제어** → 우리가 대신 제어하면 기어가기 가능.
- 바닥선: 직진 ≈ 0.05 m/s, 제자리 회전 ≈ 0.13 rad/s.
- 회전은 비싸다 → Nav2 가 제자리 회전보다 "움직이며 돌기(호)"를 고르게 하는 것도 방법.
- PWM 은 전압에 따라 속도가 변함 (11.4 → 11.07 V) → 나중에 실측 속도로 미세 보정.

## 6. v5 안전 시험 (PWM 모드, 바퀴 띄움, 0.1 m/s)
- crash 0.50 s, hang 0.81 s 정지 → 통과.
- hang 때 정지 직후 바퀴가 **뒤로 툭** (−0.19…−0.38 m/s, 0.2 s): heartbeat 가 펌웨어 PID 로 넘기는 순간,
  아직 구르는 바퀴를 PID 가 세게 브레이크 → 반대로 튐.
- 대책: PWM 모드의 정상 정지는 T:1 대신 **T:11 0** (바퀴가 먼저 멈춘 뒤 PID 로 넘어가면 PID 출력 0 → 튐 없음).
  브리지가 죽는 사고 때만 작은 뒷걸음이 남음 (정지는 됨).
