# 003 — 실물 Nav2 첫 주행의 덜컥거림 (2026-10-31)

## 증상
실물 Nav2 첫 목표(50 cm 앞) SUCCEEDED, 그런데 가는 동안 "덜컥덜컥" (섰다 출발했다 반복).

## 가설과 확인 (순서대로)
| # | 가설 | 확인 방법 | 결과 |
|---|---|---|---|
| 1 | 명령이 끊겼다 이어짐 (wander 의 잦은 정지·회전, 브리지 데드맨) | `ros2 topic pub -r 10` 으로 **일정한** 명령 | 0.1 m/s 약간 덜컥 / 0.2 부드러움 / 0.3 더 부드러움 → wander 때의 큰 덜컥은 명령 쪽 |
| 2 | 모터가 아주 느린 속도를 못 버팀 | 위 실험의 0.1 m/s | 약간 → **Nav2 최고 속도 0.15 → 0.2 m/s** |
| 3 | Nav2 명령이 중간에 0 으로 끊김 | 로그 `Robot to stop` 개수 (`tmux capture-pane -J` — 줄바꿈 이어붙이기 필수, 없으면 0 으로 잘못 셈) | **7번**, 매번 `scan ... differ on 0.22~0.23 s. Ignoring the source` |

## 원인
collision_monitor 의 `scan.source_timeout: 0.2` (TurtleBot3 기본값). 실물 라이다 스캔은 **늘 0.22~0.23 s 늦게** 도착
(한 바퀴 0.1 s 를 다 돈 뒤 보내고, 시각은 돌기 시작한 순간으로 찍힘 + 전달 시간) → "못 믿을 라이다" → 안전 정지 → 다음 스캔에 재출발.
시뮬에서도 같은 경고가 수백 번 있었지만 VM 탓으로 넘겼음 → 실물에서 주행 품질 문제로 드러남.

## 조치
`config/nav2_ugv02.yaml`: `collision_monitor.scan.source_timeout: 0.5` (0.5 s × 0.2 m/s = 10 cm, 정지 띠 7 cm·감속 띠 22 cm·저속 → 안전)

## 결과
같은 50 cm 목표: 정지 7번 → **0번**, 무시 7번 → 0번. 덜컥거림 사라짐 (Jasper: "완전 괜찮아졌다").

## 배운 것
- 경고 로그를 "환경 탓"으로 넘기면 실물에서 돌아온다. 시뮬의 반복 경고도 원인을 적어둘 것
- 로그 개수를 셀 땐 tmux 줄바꿈(-J)부터
