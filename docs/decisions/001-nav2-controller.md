# 결정 001 — Nav2 controller: MPPI (대안 RPP)

- 날짜: 2026-10-22 (시뮬 기준 1차 결정, 하드웨어 도착 후 재검증)
- 결정자: Jasper (근거 측정은 함께)

## 질문
Nav2에서 경로를 따라가며 매 순간 속도를 정하는 controller 플러그인으로 무엇을 쓸까?
기본값(TurtleBot3 설정)은 DWB.

## 목표에서 나오는 요구
- 사람이 돌아다니는 **집** 안 → 움직이는 장애물(사람)에 대응해야 함
- Raspberry Pi 5 에서 돌아야 함 → 계산량
- 나중에 사람 인식 costmap 층(Lv 8)과 함께 써야 함 → costmap 비용을 잘 반영할 것

## 측정 (시뮬, UGV02 모드 = 내 브리지 위, `robot go --laps 2~3`, A(0,0,0°) ↔ B(3,0,180°))
조건은 controller 하나만 다름. 속도 0.3 m/s, 회전 1.0 rad/s, 허용치(goal_checker) 0.25 m / 0.25 rad 동일.
오차 = Nav2가 믿는 위치(TF map→base_footprint) 기준.

| | DWB (기본) | RPP | MPPI |
|---|---|---|---|
| 성공 | 4/4 | 6/6 | 6/6 |
| 평균 시간 (3 m + 180° 회전) | 30.3 s | 21.5 s | **20.6 s** |
| 시간 범위 | 24~40 s | 19~25 s | **19~22 s** |
| 위치 오차 평균 | **6 cm** ¹ | 20 cm | 13 cm |
| 방향 오차 평균 | 11.2° | **2.2°** | 10.1° |
| 계산 밀림 (`Control loop missed`) | — | 0 | 1~2회 (batch 1000, VM) |
| 기록 | `logs/shuttle_20261022_161152.csv` | `…_172241.csv` | `…_180528.csv` |

¹ DWB만 내부에 별도 `xy_goal_tolerance: 0.05`가 있어 5 cm를 노림. RPP·MPPI는 공통 허용치 0.25 m 안에 들어오면 멈춤 → 위치 오차 차이는 controller 성능보다 **판정 기준 차이**.
1구간을 빼면 RPP 20.9 s, MPPI 20.4 s → 속도는 사실상 동률. (MPPI가 "느리게 느껴진" 건 부드러운 가속 탓으로 추정, 숫자로는 차이 없음)

## 결정
**MPPI** 1차 선택. **RPP**를 대안으로 유지.

## 이유
1. DWB 대비 시간 −32%, 시간 편차 크게 감소 (측정)
2. RPP와 속도는 동률, MPPI가 가장 일관적 (19~22 s)
3. **목표 적합성**: MPPI는 수천 개 후보 궤적을 costmap 비용으로 평가 → 움직이는 사람 회피와 나중의 사람 인식 costmap 층에 유리. RPP는 경로를 충실히 따라가고, 앞이 막히면 비켜가기보다 멈추고 재계획을 기다림.
4. VM에서 batch 1000으로 계산 밀림이 거의 없었음

## 알려진 약점 / 아직 검증 안 된 것 (정직하게)
- **움직이는 장애물 장점은 미검증**: 이번 시뮬에 움직이는 사람이 없었음
- **Pi 5 계산량 미검증**: VM(Mac 호스트)은 Pi보다 강함
- 방향 정확도는 RPP가 우수 (2.2° vs 10.1°)
- 공통: collision_monitor가 "라이다 시간 0.2 s 어긋남 → 무시 → 잠깐 정지"를 반복 (전 controller 공통, VM 시간 지연 추정) → 덜컥임 후보, 별도 조사

## 재검증 기준 (하드웨어 도착 후)
- Pi 5에서 `Control loop missed`가 주행 중 자주(예: 분당 수 회 이상) 뜨면 → batch_size 낮춰보고, 그래도 안 되면 **RPP로 전환**
- 사람이 앞을 지나갈 때 MPPI vs RPP 동작 비교 (멈춤 시간, 최소 거리)

## 이후 변경
- 10-24: `vx_min` 0.0 → **−0.2** (후진 허용). 비교 실험 때는 조건을 맞추려 후진을 막았는데, SLAM 순회에서 기둥 옆에 갇혀 273 s 멈춤 → 후진 허용 후 같은 순회 13/13, 160 s (전: 12/13, 600 s). MPPI 기본값도 후진 허용(−0.35). → RPP와 다시 비교할 땐 이 조건 차이를 감안할 것.
