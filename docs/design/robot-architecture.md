# 로봇 구성 설계 (초안, 2026-11-04 대화)

> 결정된 것과 정할 것을 한 곳에. 원칙: **"조용하되 정확하게, 빠를 필요는 없다"** (집 안 로봇).
> 장기 관점: **몸은 그대로, 뇌·감각은 업그레이드** (Pi ↔ ESP32 는 UART 한 줄 → 뇌 교체 쉬움, 펌웨어 소스 공개).

## 한눈에

| 부분 | 정해진 것 | 정할 것 |
|---|---|---|
| 몸 | UGV02 + 브리지 v5 (PWM 기어가기, heartbeat 안전 정지) | — |
| 뇌 | Raspberry Pi 5 (ROS 2 Jazzy, SLAM, Nav2) | 부하 측정 (CPU·온도 → 로그 2층 심박에 넣기), 필요 시 AI 가속기 (Hailo) |
| 머리 | 팬틸트 + 카메라. 후보 1순위: Waveshare 2축 팬틸트 ($109.99, OV5647 160° 카메라·ST3215 서보 2개·드라이버 보드 포함, 441 g) | **차체 보드로 서보를 돌릴 수 있는지** (펌웨어 gimbal 명령·서보 포트 확인), Pi 5 카메라 케이블(22핀) 포함 여부, 무게 중심 |
| 눈 | 머리에 작은 원형 화면 (1.28", 눈동자가 사람 쪽으로·깜빡임) | 나중에 |
| 귀·입 | 마이크 배열 (소리 방향 = DOA) + 스피커. Pi 5 는 3.5 mm 오디오 없음 → USB | 제품 (예: ReSpeaker USB 4-mic), 한국어 STT/TTS (로컬 vs 클라우드) |
| 에너지 | 셀 교체: 삼성 30Q (3000 mAh, 15 A) ×3, 보호회로 **없는** 것 (위키 권장, UPS 보드가 보호). 가짜 셀 주의 | UPS 보드 충전 방식 (보드가 충전 제어?) → 접점 도킹 → 무선 |
| 연결 | 아이폰 = 열쇠·리모컨: 단축어("집 Wi-Fi 연결 시") → ntfy → 로봇. 로봇에 폰을 붙이지 않음 | — |
| 버린 것 | 갤럭시 A51 (노후, 24시간 서버로 사용해 배터리 상태 나쁨), 로봇에 아이폰 고정 (없으면 못 씀) | — |

## 핵심 행동 (면접 "와" 지점)
1. **부르면 돌아보기**: "로봇아" → 마이크 배열이 방향 → 머리가 돌아감 → 카메라가 사람 찾기 → 고개 들어 얼굴 바라보기
2. **쳐다보기 → 따라가기**: YOLO 박스 중심 오차 → 머리(조용·빠름) 먼저, 많이 돌면 몸. 거리 = 그 방향 LiDAR
3. **마중**: 아이폰 단축어 → ntfy → 현관으로 → 사람 확인 → 인사
4. **의미 지도**: LiDAR 가 "뭔가 있다" 할 때만 카메라 추론 → 지도에 의자·소파 표시
5. **거리 추정 비교**: LiDAR(정답) vs 바닥 평면 투영(SimCheong raycast 원리) vs 단안 깊이
6. **스스로 충전**: Nav2 로 충전대 앞 → 충전대 감지 → 0.05 m/s 밀고 들어감 → 전압 오르면 정지
7. **일정 듣고 정리**: 캘린더 + LLM → task_manager 가 검증 후 실행

## 순서 (안)
배터리 교체·실사용 시간 → 팬틸트 결정·장착 → 쳐다보기(몸 → 머리) → 의미 지도·거리 비교 → 마이크·스피커 → 부르면 돌아보기
→ 접점 도킹 → 마중 → 무선 충전 → 일정

## 로봇의 하루 — 궁극 목표 (Jasper, 2026-11-05)

> "이걸 완성하는 게 궁극적인 목표. 이걸 할 수 있게 되면 이미 엔지니어가 되어 있을 것. 부품이 다 없어도 조금씩 채워나가면 된다."
> 지휘자 = `task_manager` (상태 머신, `docs/design/task_manager.md`). 지도·Nav2·카메라·음성은 지휘자가 쓰는 도구.

| 시간대 | 로봇이 하는 일 | 필요한 것 | 상태 |
|---|---|---|---|
| 밤 | 충전대에서 대기 | 자동 충전 (접점 도킹 → 무선) | ⬜ |
| 기상 | 침대 앞으로 와서 부르기 → 얼굴로 Jasper 확인 → 대화 → 오늘 일정·날씨 브리핑 (우산 등) | 저장 지도 + AMCL, 의미 지도(침대 지점), 얼굴 인식, 음성(STT·TTS·LLM), 캘린더·날씨 API | ⬜ (카메라 🔜) |
| 외출 후 | 혼자 SLAM 으로 집 다시 확인 → 정각마다 순회하며 가구 위치 갱신 → 사람이 있으면 대화·기록 → 나중에 공유 | 지도 다시 그리기(충전대 복귀 시), 순회 지점, 변화 감지, 기록·요약 | ⬜ |
| 배경 작업 | 크롤링, 시킨 잡일 (점점 늘어남) | Python 서비스 (systemd), 이벤트 기반 감시(RSS·IMAP IDLE·웹소켓), ntfy | ⬜ (ntfy ✅) |
| 귀가 | 현관에서 마중 → 알릴 것 전달 | 아이폰 단축어("집 Wi-Fi 연결") → ntfy → 현관 지점 | ⬜ |
| 취침 | 하루 요약, 내일 일정 받아두기, 저녁 인사 | 이벤트 로그(로그 1층) → LLM 요약, 일정 저장 | ⬜ (로그 ✅) |
| 나중 | 로봇팔(RoArm-M2, 펌웨어가 이미 지원)로 집기·정리, 가벼운 청소 | 팔 + 3D 위치 (+ 청소면 낭떠러지 센서 재검토) | ⬜ |

- **첫 완성 장면 = 아침 기상** (필요한 게 정해져 있고, 매일 쓰고, 영상 한 편으로 보여주기 좋음).
- 평소 운행 = **저장 지도 + AMCL** (SLAM 은 돌수록 메모리·계산이 늘어남 → 하루 운행엔 위치 찾기만). 새로 놓인 물건은 costmap 이 매 순간 처리, 큰 배치 변경 시에만 지도 다시 그리기.
- 자원: "늘 도는 건 가볍게, 무거운 건 필요할 때만" — 심박 로그에 프로세스별 CPU 기록해서 SLAM→AMCL 전후 숫자로 확인.
- **다른 사람과의 대화 기록**: 기록 중임을 먼저 알리고 동의할 때만, 원본보다 짧은 요약만, 로봇 안에만 저장·기간 지나면 삭제.
